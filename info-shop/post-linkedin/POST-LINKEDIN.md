# Texto sugerido

Quero compartilhar o **PetCornerNext**, um projeto full-stack que desenvolvi para centralizar a experiência de um pet shop em uma única plataforma.

A solução reúne catálogo de produtos e serviços, carrinho, checkout, agendamentos, área do cliente e painel administrativo para apoiar toda a operação. O projeto foi construído em um monorepo com **Next.js, React, TypeScript, Firebase e Stripe**.

Foi uma ótima oportunidade para trabalhar uma aplicação completa, da experiência do usuário à gestão do negócio.

🔗 Demonstração: https://pet-corner.vercel.app/
